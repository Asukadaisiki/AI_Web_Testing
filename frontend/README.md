# Frontend Status

前端服务于核心规划中的平台层和工作台层，不承载正式执行逻辑。

## 当前状态

当前 `frontend/` 仍以工程骨架和模块目录占位为主。

- 已有：目录边界、页面分层约定
- 未落地：真实页面、路由、数据请求层、组件库接入、图表接入

## 目标技术栈

- React + TypeScript
- Vite
- React Router
- TanStack Query
- Ant Design
- ECharts

## 前端落地顺序

前端执行顺序必须围绕核心规划：

1. 阶段 1：平台壳、用例编辑最小入口、执行结果查看
2. 阶段 2：定位调试区与候选元素证据展示
3. 阶段 3：DSL 编辑与 AI 生成入口
4. 阶段 4：报告中心与失败分析展示
5. 阶段 5：Suite 管理、执行中心、历史结果对比
