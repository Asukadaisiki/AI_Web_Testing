# 前端设计风格与排版

## 文档定位

本文件从属于 [AI 自动化测试增强项目规划](./AI%20自动化测试增强项目规划.md)，用于描述前端目标形态与页面设计，不单独定义产品主线。

- 前端设计必须服务于核心规划中的 Planner、Locator、Reporter、Suite Manager 展示需求。
- 正式执行能力以后端 Runner 为准，前端不承载官方执行逻辑。
- 本文件描述的是目标态和第一版页面范围，不代表当前仓库已经全部落地。

## 当前状态说明

当前仓库中的 `frontend/` 仍以工程骨架和模块目录占位为主，页面、路由和依赖尚未完整落地。

- 已有：目录边界、页面分层约定
- 未落地：React Router、TanStack Query、Ant Design、ECharts 的真实接入与页面实现

因此，下面的内容应视为“围绕核心规划的前端目标设计”，不是当前完成度说明。

## 产品定位

前端采用“平台 + 工作台”的产品形态。

- 平台层负责登录、项目空间、测试用例管理、测试执行、报告查看与导出。
- 工作台层负责编写测试步骤、页面预览、元素拾取、定位调试与执行回放。

核心目标不是模拟浏览器本身，而是把 Web UI 自动化测试流程可视化。

## 设计风格

整体风格采用中后台工作台设计，要求清晰、稳定、信息密度适中。

- 主色调：浅色背景，搭配低饱和蓝灰色作为基础色。
- 状态色：成功使用绿色，失败使用红色，运行中使用橙色，待执行使用中性灰。
- 字体：中文优先使用 `PingFang SC`、`Microsoft YaHei`，英文与代码区使用等宽字体。
- 组件风格：矩形卡片、清晰边界、弱阴影，避免过多圆角和装饰性效果。
- 动效：仅保留必要的过渡反馈，例如任务状态变化、抽屉展开、步骤高亮。

## 信息架构

建议采用左侧导航 + 顶部状态栏 + 主工作区的布局。

左侧导航包括：

- 仪表盘
- 测试用例
- 测试套件
- 执行中心
- 报告中心
- 环境配置
- 系统设置

顶部状态栏包括：

- 当前项目/空间切换
- 全局搜索
- 最近任务入口
- 用户菜单

## 关键页面排版

### 1. 仪表盘

采用卡片式概览布局。

- 顶部展示关键指标：总用例数、最近执行数、通过率、失败数、平均耗时。
- 中部展示趋势图：执行趋势、失败趋势、模块分布。
- 底部展示快捷入口：最近失败任务、常用 Suite、待修复用例。

### 2. 用例管理页

采用表格 + 侧边详情的布局。

- 左侧或顶部提供筛选项：模块、标签、优先级、创建人、更新时间。
- 中间使用表格展示用例列表。
- 右侧抽屉展示用例概要、最近执行结果与快捷操作。

### 3. 用例编辑工作台

这是核心页面，建议采用三栏布局。

- 左栏：步骤列表与 DSL 编辑器
- 中栏：被测页面预览区
- 右栏：元素信息、定位结果、执行日志、参数面板

布局重点：

- 左栏支持步骤新增、删除、排序、复制和分组。
- 中栏支持页面预览、高亮元素、执行过程回放。
- 右栏展示 target 解析、候选元素、定位评分、错误信息。

### 4. 执行中心

采用任务控制台布局。

- 列表区展示任务状态、触发方式、执行环境、开始时间、耗时。
- 详情区展示正在运行的步骤、实时日志、当前截图。
- 支持批量重跑、只重跑失败项、按条件筛选任务。

### 5. 报告详情页

采用“步骤时间线 + 证据面板”的布局。

- 顶部展示任务总览：状态、环境、浏览器、执行时间、用例名、Suite 名。
- 左侧展示步骤时间线。
- 中间展示当前步骤截图或页面快照。
- 右侧展示 URL、Console、Network 摘要、断言结果、失败原因、候选元素。

## 可视化重点

前端必须重点可视化以下四类信息：

1. 步骤流转：当前执行到哪一步、每一步做了什么、失败在哪一步。
2. 元素定位：target 是什么、召回了哪些候选、最终命中了哪个元素。
3. 证据记录：截图、URL、日志、断言结果、错误说明。
4. 测试资产：Case、Suite、标签、执行历史、失败趋势。

## 交互原则

- 正式测试执行由后端 Runner 完成，前端只做触发与展示。
- 浏览器页面预览仅作为工作台能力，不作为全站主布局。
- 用例编辑以结构化表单和 DSL 编辑器为主，录制/拾取为辅助入口。
- 报告页优先保证排障效率，不追求过度视觉包装。

## 推荐技术形态

- 框架：React + TypeScript
- 构建：Vite
- 路由：React Router
- 数据请求：TanStack Query
- UI 组件：Ant Design
- 图表：ECharts

## 第一版页面范围

第一版优先实现以下页面：

1. 登录页
2. 仪表盘
3. 用例列表页
4. 用例编辑工作台
5. 执行中心
6. 报告列表页
7. 报告详情页

## 落地顺序

前端落地顺序必须服从核心规划，而不是单独扩张页面范围：

1. 阶段 1：用例编辑最小入口、执行结果查看、基础平台壳
2. 阶段 2：定位调试区、候选元素与命中证据展示
3. 阶段 3：DSL 编辑与 AI 生成入口
4. 阶段 4：报告列表、报告详情、失败分析展示
5. 阶段 5：Suite 管理、执行中心、历史结果对比
